# Deterministic ES2015 Test262 Taxonomy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Check in the deterministic ES2015 Test262 taxonomy, audit/check tooling, and exact-path promotion required by issue #74 without changing guest runtime semantics or globally widening Test262 feature support.

**Architecture:** A host-neutral taxonomy module classifies fixture or pinned-tree inventories from explicit versioned policy, Sixth Edition anchors, Test262 metadata, transitive harness dependencies, current selection, and exact execution records. A Node CLI owns pinned-checkout I/O and generated-artifact synchronization. A separate exact promotion manifest authorizes only the 6,323 reviewed core roots and lets the runner bypass unsupported metadata tags only for those paths, while normal feature probes and broad feature claims remain unchanged.

**Tech Stack:** ECMAScript modules, Node.js 20, existing portable Test262 metadata/runner modules, JSON generated artifacts, repository test harness, generated CI pipeline, Test262 revision `b363f29d3c43c626dc852744ad64a0b48a003693`, and `TZ=UTC`.

## Global Constraints

- Start from roadmap merge `621af70d58c1bb1c368f5ecbd1d880fcd44c6726`.
- Keep Test262 pinned to `https://github.com/tc39/test262.git` at `b363f29d3c43c626dc852744ad64a0b48a003693`; a pin move is out of scope.
- Do not modify `src/` or guest runtime semantics.
- Do not add the promoted roots' feature tags to `tools/test262/features.json` or otherwise globally enable broad tags.
- Promotion is limited to the sorted 6,323-path `T0.paths.txt` ledger whose SHA-256 is `3f2c617b8639c8048afb1a42b95218250b20b6d51b9313f39473b4ddc1c7c646`.
- All generated artifacts and Test262 executions require `TZ=UTC`, are timestamp-free, and sort strings by code unit.
- Local Test262 execution is limited to the exact T0 promotion paths or smaller focused fixtures; never run the broad upstream subset locally.
- Classification precedence is exactly: malformed, harness validation, later/non-ES2015 dependency, affirmative ES2015 evidence, unknown edition, then selected-passing/audit-passing-unselected/blocked/intentional-deviation.
- Later dependency evidence overrides `es5id`, `es6id`, anchors, and ES2015 tags.
- Unknown tags, includes, anchors, path rules, missing roots, pin drift, duplicate classifications, count imbalance, or malformed unclassified metadata fail loudly.
- Reports preserve separate core, Annex B, later/non-ES2015, unknown, harness, and malformed partitions and render percentages with exactly three decimal places.
- Commits include `Co-authored-by: Copilot App <223556219+Copilot@users.noreply.github.com>`.
- Reviews use GPT-5.6-family models or Claude Opus 4.8 or lower; never Claude Opus 5.
