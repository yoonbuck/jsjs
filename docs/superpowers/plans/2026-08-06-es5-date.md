# ES5 Date Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement the complete ES5 Date family with deterministic host adapters.

**Architecture:** Store UTC milliseconds in EngineDate, implement calendar arithmetic explicitly, and isolate current-time/timezone dependencies.

### Task 1: Time arithmetic

Implement ES5 date abstract operations with boundary, leap-year, negative-time,
and clipping tests.

### Task 2: Date construction and statics

Implement call/construct overloads, parsing, UTC, now, host clock/timezone
injection, and realm wiring.

### Task 3: Accessors and mutators

Implement every local/UTC getter and setter with invalid-date and DST-boundary
tests.

### Task 4: Formatting and JSON

Implement string/locale/ISO/UTC formatting, valueOf, and toJSON integration.

### Task 5: Test262 and integration

Pin representative Date groups, update compact docs/coverage, run portable CI,
review, and publish.
