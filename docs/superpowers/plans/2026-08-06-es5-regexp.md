# ES5 RegExp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement ES5 RegExp and complete String pattern integration.

**Architecture:** Add an engine RegExp object and a host-neutral compatibility layer that validates ES5 syntax and normalizes UTF-16 matching results.

**Tech Stack:** Plain ES2020 JavaScript, strict JSDoc, portable harness, pinned Test262.

### Task 1: RegExp object and constructor

Implement call/construct overloads, flags, source, class tag, descriptors, and
ES5 syntax rejection test-first.

### Task 2: Execution semantics

Implement `exec`, `test`, `toString`, captures, global `lastIndex`, zero-width
progress, multiline and case-insensitive behavior.

### Task 3: String integration

Complete `match`, `replace`, `search`, and `split` for guest RegExp values,
including captures, replacement tokens/functions, and coercion ordering.

### Task 4: Test262 and integration

Pin representative groups, update docs/support tables and coverage artifacts,
run all portable CI contracts, review, and publish.
